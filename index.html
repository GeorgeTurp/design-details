Why this exists

There are good Claude Code skills for web animation already. But they're web-only. None of them cover React Native or SwiftUI. None of them touch haptics. Gesture orchestration, per-component press values, cross-platform spring mapping? Not there.

I built this because I'm a product designer who ships SaaS every day and got tired of adding the same press states and haptic calls to every component Claude built for me. The goal is UI that feels responsive and trustworthy, not flashy.

Every value in the skill is tested. Buttons scale to 0.96 because 0.9 looks like a bug and 0.98 is invisible. Press is faster than release because instant acknowledgment matters more than graceful recovery. Cards scale less than icon buttons because large elements need less movement to feel real.
